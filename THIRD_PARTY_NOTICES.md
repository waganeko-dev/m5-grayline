## Services

### ipinfo.io (GeoIP)

When `config.json` has no home latitude / longitude, the device asks
[ipinfo.io](https://ipinfo.io/) for its approximate location during each NTP
sync (at boot and every `ntp_interval_min` minutes). The request reveals the
public (global) IP address of your network to ipinfo.io. Set `home.lat` /
`home.lon`, or `"geoip": false`, to stop these requests. Use of the service is
subject to the ipinfo.io terms of service; an optional access token can be set
as `home.ipinfo_token`.

### NTP servers

The default NTP servers are `ntp.nict.jp`, `time.google.com` and
`pool.ntp.org`. They can be changed in `config.json`.
