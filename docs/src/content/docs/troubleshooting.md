## 起動時のメッセージ

起動時や時刻の同期中は、画面の下部にメッセージを表示します。

| メッセージ | 意味と対処 |
| --- | --- |
| `SD not found: using defaults` | microSD カードを認識できません。既定値 (Wi-Fi なし、自局は東京など) で動作します。カードが奥まで挿さっているか、FAT32 でフォーマットされているかを確認してください。 |
| `config.json error: ...` | `config.json` の JSON の書き方に誤りがあります。既定値で動作します。カンマや引用符の過不足を確認してください。 |
| `Cannot write config: using defaults` | `config.json` を作成できませんでした。カードが書き込み禁止になっていないかを確認してください。 |
| `Created /grayline/config.json` | `config.json` を新しく作成しました。Wi-Fi の設定を記入してください。 |
| `Updated /grayline/config.json` | 古い形式の `config.json` に、新しい設定項目を既定値で追加しました。 |
| `No Wi-Fi in config.json` | `wifi.ssid` が空です。[設定 (config.json)](../config/) を参照して記入してください。 |
| `Wi-Fi failed (st=..., ssid found)` | 指定した SSID は見つかりましたが、接続できませんでした。パスワードを確認してください。 |
| `Wi-Fi failed (st=..., ssid not found - 2.4GHz?)` | 指定した SSID が見つかりません。SSID の綴りを確認してください。本体は 2.4GHz 帯にのみ対応しており、5GHz 帯のネットワークには接続できません。 |
| `NTP failed` | Wi-Fi には接続しましたが、時刻を取得できませんでした。ネットワークで NTP (UDP 123 番ポート) が通るかを確認するか、`time.ntp` に別のサーバーを指定してください。 |

## 時刻が合わない、UTC が赤く表示される

NTP で時刻を同期できていません。同期できるまでは、ファームウェアのビルド時刻を仮の時刻として使います。上の表のメッセージを確認し、Wi-Fi の設定を見直してください。ボタン A を押すと、すぐに再同期します。同期に失敗した場合は、30 分ごとに自動で再試行します。

現地時刻だけがずれている場合は、`time.tz_offset_min` (UTC との時差、分) を確認してください。夏時間には自動で切り替わりません。

## 自局の位置がずれている

詳細画面の右上に `GeoIP` と表示されている場合、位置は回線のグローバル IP アドレスから推定したものです。プロバイダーによっては、実際の場所から大きく離れることがあります。`home.lat` と `home.lon` を設定してください。

`default` と表示されている場合は、緯度経度の設定がなく、GeoIP も使えなかったため、東京を使っています。

## 画面が暗い

夜間 (自局の太陽高度が `display.day_alt_deg` 以下) や、バッテリー動作中は画面を暗くします。暗いときにボタンを押すと、`display.wake_sec` 秒の間だけ明るくなります。暗いときの明るさは `display.dim_brightness` で変えられます。

## ボタンが効かない

画面が暗いときに押したボタンは、画面を明るくするだけで、操作としては扱いません。明るくなってから、もう一度押してください。

## 書き込みできない、ポートが見つからない

- USB ケーブルが充電専用でないか (データ通信に対応しているか) を確認してください。
- パソコンの OS によっては、USB シリアル変換 IC (CH9102) のドライバーが必要です。M5Stack の公式ドキュメントから入手してください。
- Web Flasher は、パソコンの Google Chrome と Microsoft Edge でのみ動作します。
- ほかのアプリケーション (シリアルモニターなど) がポートを開いていると、書き込めません。

## 設定を最初からやり直したい

microSD の `/grayline/config.json` を削除してから起動すると、既定値で作り直します。Wi-Fi の設定も消えるため、記入し直してください。
