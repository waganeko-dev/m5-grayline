title: Changelog
description: Where to find the changelog and releases of m5-grayline.
---

Changes are recorded in [CHANGELOG.md](https://github.com/waganeko-dev/m5-grayline/blob/main/CHANGELOG.md) in the repository (in Japanese).

Firmware for each release (full image and application-only image) is available on [GitHub Releases](https://github.com/waganeko-dev/m5-grayline/releases). The [Web Flasher](../flasher/) installs the latest release.

Version numbers follow [Semantic Versioning](https://semver.org/). The major version is raised for incompatible changes to the `config.json` format or a change of the target hardware. Versions stay at `0.x` until the requirements are settled.
